# BookmarkOrganizer 书签整理助手

浏览器扩展：书签树形可视化、拖拽整理、智能分类、死链检测、WebDAV 跨设备同步，**全部操作本地完成**。

## 解决什么问题

书签一多就乱：想整理没有顺手的树形视图，想分类要一条条拖，想清理死链要一个个点。**书签整理助手**把这些压成一个弹窗：

- 树形可视化浏览，**拖拽**即移动，支持多选批量操作与即时搜索
- 递归排序、合并同名文件夹、清理空文件夹、移除重复书签，一键完成
- 内置规则（域名 / 关键词 / 正则 / 组合）自动分类，支持相似书签聚类
- **死链检测真并发后台运行**——点完「开始检测」即可关掉弹窗继续浏览，随时回来看进度，浏览器重启也能断点续检
- 多文件 HTML / JSON 书签**合并导入**，URL 自动去重，进度可见
- **WebDAV 跨设备同步**（兼容坚果云等标准服务），双向合并 / 上传 / 下载覆盖，支持定时自动同步

所有长任务（死链检测、合并导入、全量排序、批量移动）都在后台任务引擎中执行，进度实时持久化，后台进程被回收后自动续跑，任务全部幂等、重复执行不产生脏数据。

## 安装

### Chrome / Edge（及任意 Chromium 系）

1. 到 [Releases](../../releases) 下载 `BookmarkOrganizer-chrome-*.zip` 并**解压**
2. 打开 `chrome://extensions`，右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择解压出的文件夹

### Firefox / Zen

到 [Releases](../../releases) 下载 `BookmarkOrganizer-firefox-*.xpi`，拖入浏览器或从附加组件管理器「从文件安装附加组件」。

> Firefox 系浏览器默认不自动授予网站访问权限：使用死链检测前，请在附加组件管理器 → 本扩展 → 权限中允许「访问所有网站的数据」，否则检测结果会全部显示为网络错误。

### 360 安全浏览器 / 360 极速浏览器 / 旧版 Edge 及其他旧 Chromium 内核

不支持 MV3 的旧内核请下载 `BookmarkOrganizer-legacy-mv2-*.zip` 并**解压**，在扩展管理页开启开发者模式后「加载已解压的扩展程序」。此包使用 MV2 清单，后台页常驻，长任务不受空闲回收限制。

## 使用提示

- 死链检测的并发数与超时时间可在扩展「设置」页调整
- 建议一次性完成死链检测，非必要不要中途点「停止检测」
- WebDAV 同步填写服务器地址、账号与应用密码即可，「双向合并」是最安全的日常同步方式

## 隐私

- 不收集、不上传任何数据；无任何统计或遥测
- 唯一的网络请求是死链检测对书签 URL 本身的存活探测（GET 请求），以及你自行配置的 WebDAV 同步

## 从源码构建

```bash
node build-firefox.js   # 产出 Firefox/Zen 用的 xpi（Zen 运行中会跳过部署）
node build-chrome.js    # 产出 Chrome 用的 zip
```
